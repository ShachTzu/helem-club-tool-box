The `ManageGallery` component is a full CRUD admin panel for the PTSDART community gallery. It lets admins create, edit and delete gallery items (title, description, media url/type, artist name and coping-domains), guarded behind the admin role, and is meant to be registered as an `AdminPanel` in the platform admin shell. RTL by default.

## Usage

### Basic usage with mock data

```tsx
const domains = [
  { id: 'anxiety', slug: 'anxiety', name: 'חרדה', icon: '😰', count: 5 },
  { id: 'sleep', slug: 'sleep', name: 'שינה', icon: '🌙', count: 3 },
];

const items = [
  {
    id: '1',
    slug: 'quiet-after-the-storm',
    title: 'שקט אחרי הסערה',
    mediaType: 'image' as const,
    mediaUrl: 'https://example.com/art.png',
    thumbnailUrl: 'https://example.com/art.png',
    artistName: 'נועה ל.',
    domains: ['anxiety'],
    createdAt: '2026-01-12T09:00:00.000Z',
  },
];

const admin = {
  id: 'admin-1',
  email: 'admin@helemclub.org',
  displayName: 'הלם אדמין',
  role: 'admin' as const,
  provider: 'google' as const,
  createdAt: '2024-01-15T09:30:00.000Z',
};

<ManageGallery mockItems={items} mockDomains={domains} mockUser={admin} />
```

### Registering as an AdminPanel

`ManageGallery` is meant to be registered as a panel entry in the platform's admin shell, so it appears in the admin navigation alongside other management panels.

```tsx
const panels = [
  { id: 'gallery', label: 'ניהול גלריה', path: '/admin/gallery', component: ManageGallery, roles: ['admin'] },
];
```

### Access denied for non-admin users

Signed-in users without the admin role see an access-denied message instead of the panel content.

```tsx
const member = {
  id: 'member-1',
  email: 'sam.doe@example.com',
  displayName: 'סם דו',
  role: 'member' as const,
  provider: 'email' as const,
  createdAt: '2024-01-15T09:30:00.000Z',
};

<ManageGallery mockUser={member} mockItems={[]} />
```
