A component for a KnowledgePage entity, supports serialization and de-serialization of KnowledgePage objects and can be used from
both backend and frontend.

## Get started

Install and use the entity to create a new instance:

```ts
const knowledgePage = KnowledgePage.from({
  name: 'hello'
});
```
