import { MemoryRouter } from 'react-router-dom';
import { mockLabels } from '@helemclub/knowledge-base.entities.label';
import { KnowledgePreview } from './knowledge-preview.js';

The `KnowledgePreview` section shows a compact grid of the knowledge base's project
labels, with a "see all" link to the full knowledge base. It is registered into the
platform's `HomeSection` slot by the knowledge-base aspect, so it appears on the home
page without the platform depending on the knowledge-base scope.

## Default

```jsx live
<MemoryRouter>
  <KnowledgePreview mockLabels={mockLabels()} />
</MemoryRouter>
```

## Limited to three labels

```jsx live
<MemoryRouter>
  <KnowledgePreview mockLabels={mockLabels()} limit={3} />
</MemoryRouter>
```
