The knowledge base aspect maintains a searchable collection of externally hosted media records, organized by labels, and exposes both a GraphQL API and browser routes for the knowledge lobby, label lobby, and record pages.

## List and filter records

This example shows a simple panel that renders a list of knowledge base media records, filtered by label and free text query, similar to what the listRecords query would return.

## Single record view with view count

This example demonstrates a record page that displays a single media record and shows how the view count would increment when the record is opened, mirroring the getRecord mutation behavior.

```tsx
function RecordPagePanel() {
  const initialRecord = {
    id: '3',
    slug: 'media-preservation-guide',
    title: 'Media Preservation Guide and Audio Tools',
    mediaUrl: 'https://res.cloudinary.com/ddnr1ptva/image/upload/f_auto,q_auto/ai-images/get/g7e545b13d34663eef384a3b4bb7aa363a0d9760e33dd0b436a67cb2c17a1caaefdd25693e80379fe299d40bde224da893ae1ff9cd2f43312e8741f9f83e0b137_1280.png',
    domains: ['audio', 'preservation'],
    viewCount: 89,
  };

  const displayedRecord = { ...initialRecord, viewCount: initialRecord.viewCount + 1 };

  return (
    <div style={{ maxWidth: 480, padding: 16, border: '1px solid #eee', borderRadius: 8 }}>
      <img
        src={displayedRecord.mediaUrl}
        alt={displayedRecord.title}
        style={{ width: '100%', borderRadius: 8 }}
      />
      <h2>{displayedRecord.title}</h2>
      <div style={{ fontSize: 13, color: '#666' }}>
        Domains, {displayedRecord.domains.join(', ')}
      </div>
      <div style={{ fontSize: 13, color: '#666', marginTop: 4 }}>
        Views, {displayedRecord.viewCount}
      </div>
    </div>
  );
}

export const RecordPagePanelExample = () => <RecordPagePanel />;

```

## Labels dashboard panel

This example shows a dashboard panel listing the knowledge base labels, which represent the projects or collections used to group media records, useful for building navigation or an admin overview.

```tsx
function LabelsDashboardPanel() {
  const labels = [
    { id: '1', slug: 'community-archive', name: 'מאגר הקהילה' },
    { id: '2', slug: 'audio-history', name: 'היסטוריה קולית' },
    { id: '3', slug: 'documentaries', name: 'סרטים תיעודיים' },
  ];

  return (
    <div style={{ display: 'flex', gap: 12, padding: 16, flexWrap: 'wrap' }}>
      {labels.map((label) => (
        <div
          key={label.id}
          style={{
            padding: '12px 16px',
            borderRadius: 8,
            background: '#f5f5f5',
            fontWeight: 600,
            minWidth: 140,
            textAlign: 'center',
          }}
        >
          {label.name}
        </div>
      ))}
    </div>
  );
}

export const LabelsDashboardPanelExample = () => <LabelsDashboardPanel />;
```
