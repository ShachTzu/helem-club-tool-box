The `ManageAuthors` component is an admin panel for managing blog authors. It lists all authors, shows how many posts each one has published and the date of their last post, and lets an admin grant or revoke write permission. The panel is protected — only users with the `admin` role can view it — and is designed to be registered as an `AdminPanel` in the platform's admin shell.

## Usage

### Basic usage

```tsx
function ManageAuthorsExample() {
  return <ManageAuthors />;
}
```

### Registering as an AdminPanel

The component is intended to be registered as an admin panel entry in the platform's admin shell, alongside the other management panels (users, toolbox, moderation, etc). It renders its own protection logic, so it can safely be used as the panel's `component`.

```tsx
function AdminPanelsExample() {
  const panels = [
    { id: `blog-authors`, label: `ניהול כותבים`, path: `/admin/blog/authors`, component: ManageAuthors },
  ];

  return <p>נרשמו {panels.length} פאנלים לאזור הניהול.</p>;
}
```
