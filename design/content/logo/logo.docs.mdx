The `Logo` component renders the Helam Club brand mark as a link to the homepage. The artwork ships bundled with the component, so it renders identically everywhere the component is used — no app-level asset setup required.

The mark is decorative (`alt=""`) and the link itself carries `aria-label="הלם קלאב"`, so screen readers announce the destination once rather than twice.

It supports multiple sizes and light/dark variants so it can be used seamlessly in the header and footer (dark surfaces) as well as on light surfaces.

## Usage

Render the default logo, linking to the homepage:

```tsx
<Logo />
```

## Sizes

The `size` prop controls the mark height — 24px, 32px or 44px — with width derived from the aspect ratio so the artwork never distorts. Useful for adapting the logo to a compact mobile header versus a large hero section:

```tsx
<div style={{ display: 'flex', gap: 20, alignItems: 'center' }}>
  <Logo size="small" />
  <Logo size="medium" />
  <Logo size="large" />
</div>
```

## Light and dark variants

The variant names the surface, not the artwork. Use `variant="dark"` (the default) on dark surfaces like the primary-colored header and footer — it renders the white mark. Use `variant="light"` on light surfaces — it renders the dark mark:

```tsx
<div style={{ display: 'flex', gap: 24 }}>
  <div style={{ padding: 16, background: 'var(--colors-primary-default)' }}>
    <Logo variant="dark" />
  </div>
  <div style={{ padding: 16, background: 'var(--colors-surface-background)' }}>
    <Logo variant="light" />
  </div>
</div>
```

## Custom destination

Pass a custom `href` to change the link destination, for example for admin or partner sub-sites:

```tsx
<Logo href="/admin" size="small" />
```
