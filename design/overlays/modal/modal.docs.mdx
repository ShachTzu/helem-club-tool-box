The `Modal` component renders a centered dialog above a dimmed overlay. It closes on backdrop click or the escape key, supports RTL layouts, and collapses into a full-screen bottom sheet on mobile screens. Use it for confirmations, forms, and lightboxes.

## Basic usage

Control the modal's visibility with the `open` prop and provide an `onClose` callback:

```tsx
function Example() {
  const [open, setOpen] = React.useState(false);

  return (
    <div>
      <button onClick={() => setOpen(true)}>פתיחת חלון</button>
      <Modal open={open} onClose={() => setOpen(false)} title="אישור פעולה">
        <p>האם אתם בטוחים שברצונכם להמשיך?</p>
      </Modal>
    </div>
  );
}
```

## Modal with footer actions

Pass action buttons through the `footer` prop, and control the dialog width with `size`:

```tsx
function ConfirmExample() {
  const [open, setOpen] = React.useState(false);

  return (
    <div>
      <button onClick={() => setOpen(true)}>מחיקת פריט</button>
      <Modal
        open={open}
        onClose={() => setOpen(false)}
        title="מחיקת פריט"
        size="small"
        footer={
          <>
            <button onClick={() => setOpen(false)}>ביטול</button>
            <button onClick={() => setOpen(false)}>מחיקה</button>
          </>
        }
      >
        <p>הפריט יוסר מרשימת המועדפים שלכם.</p>
      </Modal>
    </div>
  );
}
```

## Lightbox for images

Use a `large` size and disable the default padding assumptions by nesting an image directly in the body:

```tsx
function LightboxExample() {
  const [open, setOpen] = React.useState(false);

  return (
    <div>
      <button onClick={() => setOpen(true)}>צפייה ביצירה</button>
      <Modal open={open} onClose={() => setOpen(false)} title="מעגל של אור" size="large">
        <img
          src="https://storage.googleapis.com/bit-generated-images/images/image_abstract_expressive_painting_r_0_1785186182689.png"
          alt="מעגל של אור"
          style={{ width: '100%', borderRadius: 12 }}
        />
      </Modal>
    </div>
  );
}
```

## Behavior notes

- Clicking the backdrop closes the modal unless `closeOnBackdropClick` is set to `false`.
- Pressing the `Escape` key closes the modal unless `closeOnEsc` is set to `false`.
- On small screens (480px and below) the modal becomes a full-screen sheet anchored to the bottom of the viewport.
- Set `hideCloseButton` to hide the built-in close (x) button when a footer action already provides a way to dismiss the modal.
